# Homebrew tap for Snapix

[Snapix](https://github.com/Arrows78/Snapix) is a menu-bar screenshot, annotation and OCR tool for macOS.

## Install

```bash
brew install arrows78/snapix/snapix
```

Use the full name above. Homebrew 7 only loads casks from third-party taps you trust, and naming the tap in the command trusts that cask. If you ran `brew tap arrows78/snapix` first, trust the tap before installing:

```bash
brew trust --tap arrows78/snapix
brew install --cask snapix
```

Update with `brew upgrade --cask snapix`.

## First launch

Snapix is signed ad hoc and not notarized, so macOS blocks the first launch. Open **System Settings › Privacy & Security** and click **Open Anyway**, or run:

```bash
xattr -dr com.apple.quarantine /Applications/Snapix.app
```

## Uninstall

```bash
brew uninstall --cask snapix         # keeps your settings
brew uninstall --zap --cask snapix   # also removes Snapix's settings
```

Your saved screenshots in `~/Pictures/Snapix` are never removed.

## About this repository

`Casks/snapix.rb` is generated by the release workflow of the [Snapix repository](https://github.com/Arrows78/Snapix) on every release. Do not edit it by hand.
